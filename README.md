# The-STORM
Scary.

**Wither Storm** is a single-file, top-down HTML5 Canvas fan game inspired by *Minecraft: Story Mode*.
You play as the Wither Storm: tractor-beam the world into yourself, grow through Phases 0–7, hunt Jesse,
survive the Formidibomb, and defend the Command Block in the Bowels.

Open `wither_storm.html` in any modern desktop browser. There's no build step, no server, and no external assets.
All art is procedural pixel art and all sound is synthesized with Web Audio.

| Key | Action |
|---|---|
| W A S D | Move |
| Mouse | Aim the heads |
| V (or right mouse) | Tractor beam from the active head (a fixed-width ray that stops at the first block) |
| E (or left mouse) | Fire a Wither Skull |
| Q | Tentacle slam at the cursor (Phase 1+) |
| 1 / 2 / 3 | Select head |
| Shift | Chase burst (Phase 4+) |
| M | Full map |
| P | Pause |
| R | Restart |
| N | Mute |
| H | Show/hide the controls panel |
| F3 | Debug overlay |
